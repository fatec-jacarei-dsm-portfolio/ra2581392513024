Fatreck

Descrição
Aplicação web para a Fatec Jacareí divulgar os horários de aula e as salas de cada curso, com mapa interativo dos ambientes, ingestão de dados por CSV e exportação em PDF.
Contribuição pessoal

Tecnologias
HTML · CSS · JavaScript · Node.js · PostgreSQL · Figma

Dados Limnológicos

Descrição
Aplicação web para visualizar e disseminar dados limnológicos e meteorológicos dos reservatórios de Furnas, coletados pelo SIMA e em campanhas de campo, com painéis, tabelas, exportação em CSV e mapa interativo.
Contribuição pessoal

Tecnologias
React · TypeScript · Node.js · PostgreSQL · Leaflet · Docker

Passe

Descrição
